# LearnLoop - E-Learning Platform (React JS)

Pages: Home, Courses, Course Details, My Learning, Login, Registration.

## Run
npm install
npm run dev

## Build
npm run build

Data: dummy courses in src/data.js. Users, login session, enrollments and lesson progress are saved in LocalStorage.
Deploy: Vercel/Netlify ready (vercel.json and public/_redirects handle page refresh on routes).
